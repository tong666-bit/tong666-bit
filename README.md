# 把 AI 变成会解释的学习伙伴

我在维护两个中文教学 Agent Skills：英语讲证据，数学讲推导。希望它们帮助学习者看懂方法、定位错因，然后独立完成下一题。

| 项目 | 适合谁 | 先看效果 |
|---|---|---|
| [刘晓艳风格英语陪练](https://github.com/tong666-bit/liu-xiaoyan-skill) | 四六级、考研英语一/二；阅读、听力复盘、长难句、写译 | [三分钟讲题示意](https://github.com/tong666-bit/liu-xiaoyan-skill/blob/master/examples/showcase.md) |
| [宋浩风格数学陪练](https://github.com/tong666-bit/song-hao-math) | 本科高数、线代、概率统计、复变；考研数学按科目适配 | [三分钟板书示意](https://github.com/tong666-bit/song-hao-math/blob/main/examples/showcase.md) |

两者都采用 `SKILL.md + references/`，提供Claude Code安装步骤。参考资料按题型加载，不需要项目专属API密钥、付费课程或本项目服务器；运行仍需要你自己的AI工具。

**非老师本人或官方出品。**风格服务理解，原创示例标明自编，资料来源可追溯。

## 可以从一道错题开始

- 英语：“请对比原文与选项，告诉我哪里发生了范围或因果偷换。”
- 数学：“请找我第一处不成立的推理，补条件，再给一个变式。”
